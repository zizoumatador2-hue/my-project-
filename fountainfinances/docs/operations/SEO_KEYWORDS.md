## Rules

- One cluster per page. Do not create near-duplicate pages that compete for the same cluster.
- Never invent lender data (rates, fees, credit minimums, approval odds). Use only verified, sourced figures.
- Never promise or imply search rankings or traffic outcomes.
- For clusters 8 and 9, base content on primary government sources (HUD and StudentAid.gov respectively).
