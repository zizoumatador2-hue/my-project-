Searching for ways to speed up Windows for gaming returns a mountain of advice, most of it repeated, much of it outdated and some of it harmful. The truth is more boring and more useful: a clean, updated, cool system with fewer things fighting the game for resources will perform consistently. There is no secret switch.

This guide covers the changes that are safe, reversible and measurable, in an order that lets you check each one. For wider performance advice, see [how to increase FPS on PC](/gaming-performance/how-to-increase-fps-on-pc/) and [how to reduce input lag](/gaming-performance/how-to-reduce-input-lag-on-pc/), as well as our [complete gaming tips guide](/#pillar).

## Before you change anything: create a restore point

A restore point lets you roll back system changes. Search for **Create a restore point** in the Start menu, choose your system drive and select **Create**. Learn more about [System Restore](https://en.wikipedia.org/wiki/System_Restore). Also note your current FPS in a test scene so you can compare afterward, and write down any setting you change.

## 1. Keep Windows and drivers up to date

- **Windows Update:** install pending updates, then restart. Updates include security fixes and sometimes gaming-related fixes.
- **Graphics driver:** download the latest from your GPU manufacturer. Do a clean install if you have had problems.
- **Chipset and other drivers:** get them from your motherboard or laptop maker's support page. Avoid third-party "driver updater" tools.
- **BIOS updates:** only if the manufacturer recommends them to fix a specific issue, and follow instructions carefully.

## 2. Turn on Game Mode

Game Mode is designed to prioritize your game and limit background interruptions such as Windows Update installing drivers. Open **Settings**, then **Gaming**, then **Game Mode**, and turn it on. Its effect varies by PC and game, so test with it on and off. It is safe to leave enabled.

## 3. Choose the right power mode

In **Settings**, then **System**, then **Power**, choose a performance-focused power mode. Laptops often limit performance on battery, so plug in the charger. If you see inconsistent clock speeds on a desktop, try the highest performance mode and watch temperatures. Higher performance modes use more power and can raise fan noise, so use them while gaming rather than all day.

## 4. Remove unnecessary startup apps

Many programs start with Windows and keep running in the background. To check:

1. Open **Task Manager** and choose the **Startup apps** tab.
2. Sort by **Startup impact**.
3. Disable what you do not need, such as chat apps, cloud sync clients or updaters.
4. Leave security software and drivers you recognize.

Disabled apps still work when you open them manually, so this is easily reversed.

## 5. Reduce background capture and overlays

Game recording and overlays use CPU, GPU and disk:

- **Background recording:** in the Windows Gaming settings, turn off the option to record in the background if you do not use it.
- **Overlays:** chat, hardware monitoring, game platform and driver overlays all add small amounts of load. Keep the ones you use and disable the rest.
- **Capture tools:** make sure only one recording tool runs at a time.

If you do record gameplay for review, which we recommend in [how to review your gameplay](/advanced-strategies/how-to-review-your-gameplay/), choose a lightweight capture setting and check your frame rate.

## 6. Configure graphics settings in Windows

Open **Settings**, then **System**, then **Display**, then **Graphics**:

- **Per-app GPU preference:** on laptops with two GPUs, assign the dedicated GPU to your games.
- **Hardware-accelerated GPU scheduling:** available on many modern systems. Some PCs see benefits and others do not, so test, and revert if you see problems.
- **Optimizations for windowed games:** can improve latency in borderless windowed mode on supported systems.
- **Refresh rate:** confirm your monitor is at its highest refresh rate, as in our [monitor settings guide](/game-settings/best-gaming-monitor-settings/).

## 7. Schedule updates and tasks outside play time

Surprise updates and scans cause stutter. In **Windows Update**, set **Active hours** so restarts do not occur while you play. Schedule antivirus scans and backups for times when you are not gaming. Keep security software enabled; the small performance gain from disabling it is not worth the risk.

## 8. Keep your storage healthy

- **Free space:** leave at least 10 to 15 percent of your game drive free for best results.
- **SSD for games:** install the games you play most on an SSD for faster loading and fewer asset-streaming stutters.
- **Cleanup:** use **Storage settings** and **Storage Sense** to remove temporary files. Avoid third-party cleaners.
- **Drive health:** if you have frequent stutter, check your drive's health with the manufacturer's tool.

## 9. Mouse and input settings

Open the mouse control panel and turn off **Enhance pointer precision**, which adds acceleration. See [best sensitivity settings for gaming](/game-settings/best-sensitivity-settings-for-gaming/) for why consistency matters. Also turn off sticky key shortcuts if you play games that use Shift repeatedly, to avoid interruptions.

## 10. Notifications and interruptions

Use **Focus** or **Do not disturb** mode so notifications do not interrupt a match. This is not a performance setting, but a pop-up in the middle of a fight is a real problem.

## 11. Temperatures and dust

A hot PC slows down no matter how well Windows is configured. Monitor CPU and GPU temperatures while gaming, and clean dust from filters, fans and heatsinks regularly. See [how to increase FPS on PC](/gaming-performance/how-to-increase-fps-on-pc/) for a thermal checklist.

## What not to do

- **Do not use registry cleaners or "PC booster" tools.** They rarely help and can cause harm.
- **Do not disable Windows security features** such as Memory Integrity or Windows Security for tiny gains.
- **Do not run unknown "debloat" scripts** you have not read, because they can remove features you need.
- **Do not turn off essential services.** The risk outweighs the reward.
- **Do not skip the restore point.** It takes a minute.

## Measure the result

Compare your test scene before and after. If one change made a difference, keep it. If nothing improved, your limit is probably in a game setting, a thermal problem or the hardware. Our guide to [fixing crashes and stuttering](/troubleshooting/fix-game-crashes-and-stuttering/) goes through the other causes. For tuning the game itself, see the [FPS settings guide](/game-settings/best-fps-settings-for-better-performance/).

## A realistic maintenance routine

1. **Weekly:** restart your PC, check for pending updates and close unneeded apps.
2. **Monthly:** update your graphics driver if a new one fixes issues in your games, and check storage.
3. **Every few months:** clean dust and review startup apps.
4. **Before big games:** check your launcher for updates and let shaders compile.

## Laptops need a little extra care

Gaming laptops have different limits from desktops, and a few additional steps matter.

- **Plug in the charger.** Most laptops reduce performance on battery.
- **Use the manufacturer's performance mode,** if there is one, in addition to the Windows power mode.
- **Keep vents clear.** Use a hard, flat surface or a cooling stand, and avoid beds and sofas.
- **Clean the vents and fans** occasionally, within what the manufacturer allows.
- **Choose the right GPU.** Many laptops switch between integrated and dedicated graphics. In Windows graphics settings, set your games to use the dedicated GPU.
- **Mind the noise.** Performance modes raise fan speeds. Decide whether you prefer quiet or performance for each game.

## A simple before-and-after testing method

Because many tweaks have small effects, test them properly.

1. **Pick a test scene** that you can repeat, such as a practice range or a spot in a single-player game.
2. **Record the average FPS and the 1 percent lows** with an overlay or monitoring tool, over about a minute.
3. **Make one change.**
4. **Repeat the test** and compare.
5. **Keep the change** if it improved things or made the PC quieter and more stable. Revert it if not.

If you cannot measure any difference, the change is probably not worth keeping. Fewer changes mean fewer things that can go wrong.

## Troubleshooting common Windows gaming problems

| Problem | Things to try |
|---|---|
| Game stutters after a Windows update | Update graphics drivers, check for game patches, restart |
| FPS drops while recording | Lower recording quality or use a lighter tool |
| Game runs on the wrong GPU | Assign the game to the dedicated GPU in Windows graphics settings |
| Sudden freezes during play | Check background tasks, temperatures and disk health |
| Mouse feels inconsistent | Turn off Enhance pointer precision and check polling rate |
| Audio crackles | Update audio drivers and check the sample rate settings |

For deeper causes, see [how to fix game crashes and stuttering](/troubleshooting/fix-game-crashes-and-stuttering/).

## What to do after a major Windows update

Big Windows updates sometimes change settings or reset your preferences. After one, take ten minutes to check the basics.

- Confirm that your monitor's refresh rate is still set correctly.
- Check that Game Mode and your power mode are as you left them.
- Confirm that your games still use the dedicated graphics card.
- Update your graphics driver if a new version is available.
- Test your usual game for a few minutes and compare frame rate with your notes.

Keeping a short note of your preferred settings makes this quick.

## Key takeaways

- Create a restore point before you change anything.
- Keep Windows and graphics drivers current, and turn on Game Mode.
- Trim startup apps, background recording and overlays you do not use.
- Set active hours for updates, keep free space on your game drive and watch temperatures.
- Skip registry cleaners, booster tools and unknown debloat scripts.

A clean, updated, cool system performs consistently, and that is the real goal. There is no hidden switch that does more than these basics.
