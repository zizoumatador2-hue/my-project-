# Editorial checklist (run on every article before publishing)
- [ ] Primary keyword in title, first 100 words and one H2; answer in the first 100 words
- [ ] Title ≤ 60 chars, description ≤ 155 chars, one H1, no skipped heading levels
- [ ] Every number/claim is supported by a reputable source or removed; no invented studies, stats, reviews or personal-testing claims
- [ ] Wellness content: cautious wording ("may"), medical disclaimer shown, no treatment claims
- [ ] 3+ internal links (hub + related + pillar), 2+ authoritative external links, all working
- [ ] FAQ has 4–6 genuine questions; key takeaways present
- [ ] Image + alt text added; `modifiedDate` updated only on substantial changes
- [ ] Affiliate links use `rel="sponsored nofollow"` and the disclosure is visible
- [ ] Plagiarism/duplicate check; reads naturally in American English
