# ChayStore weekly follow-up plan

Goal: track indexing, visibility and clicks, fix weak pages, and publish 2 to 3 useful articles a week.
Time: about 45 minutes every Sunday, then publishing during the week.

## 1. Performance report (15 min)
Search Console > Performance > last 7 days, compared with the previous week.
- Record clicks, impressions, average position and CTR in `docs/metrics.csv`.
- Queries tab: record the top 10 queries. Add new ones to `docs/keyword-tracker.csv`.
- Pages tab: find pages with many impressions and CTR under 2%. Rewrite their title (60 characters max) and description (160 max).

## 2. Indexing (10 min)
Search Console > Pages (Indexation):
- Note the indexed count against last week.
- Note the reasons for non-indexing. "Crawled - currently not indexed" usually means the page needs more substance or more internal links.
- Send any error name and message for review.

## 3. Safety and policy (5 min)
Security and Manual Actions. If there is any message, stop publishing and report it immediately.

## 4. Publishing (during the week)
- 2 to 3 articles from `docs/content-calendar.md`. Run each one through `docs/editorial-checklist.md` before publishing.
- After each publish: URL Inspection on the new link, then "Request indexing".
- Every new article links to at least 2 existing articles and to its hub page.
- Pinterest: 5 to 10 pins per new article, once the business account exists.

## 5. Tool checks (5 min)
- Sitemaps: status should stay "Success".
- Core Web Vitals: check for mobile problems.

## Immediate action triggers
- Impressions drop to zero for 3 days or more.
- Any message in Manual Actions.
- A clear rise in rejected or excluded pages.

## Notes
- The first 4 weeks are for indexing. Rankings and traffic need time to build, so do not judge the site by week-one numbers.
- Do not request indexing for dozens of URLs in one day. The daily quota is limited.
- Do not buy links or stuff keywords into pages.
